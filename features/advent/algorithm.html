Bбилетики: 25, 50, 75 или 100–да

Одна попытка стоит 100 монеток и даёт ровно одну награду. За ивент у пользователя 18 попыток. Все 6 предметов A он обязан получить за эти 18 попыток, S – как повезёт.

Вероятности обычной попытки

Сначала выбирается группа, потом приз внутри неё.

  • Полученный предмет A или S больше не выпадает. Его вес делится между оставшимися в той же группе.
  • Собраны все A – их 25% уходят в B: дальше B 99,46%, S 0,54%.
  • Собраны все S – их 0,54% тоже уходят в B.

Гаранты: когда случайность не работает

  1. Добор A. Недостающих A столько же, сколько осталось попыток до 18-й, считая текущую, – выдаём A без розыгрыша. Например, не хватает 2 A, осталось 2 попытки – обе дадут A. S на таких попытках не выпадает.
  2. Первая попытка. Если выпали билетики – меняем их на A.
  3. Серия билетиков. Пока A не собраны, подряд может выпасть не больше 3 раз B. На следующей попытке B меняется на A. Выпали A или S – счётчик серии обнуляется.

Выпавший S никогда не меняется на A и не отменяет обязанность выдать все 6 A. Гарант не добавляет вторую награду, а заменяет билетики на предмет. После сбора всех A гаранты 2 и 3 больше не нужны.

Псевдокод

// состояние пользователя
attempt   = 0          // сколько попыток уже сделано
collected = []         // полученные предметы A и S
bStreak   = 0          // сколько раз подряд выпали билетики

function spin():
    attempt   = attempt + 1
    missingA  = все A, которых нет в collected
    missingS  = все S, которых нет в collected
    slotsLeft = 18 - attempt + 1          // оставшиеся попытки, считая эту

    // 1. добор A
    if missingA не пуст and size(missingA) >= slotsLeft:
        group = A

    else:
        // 2. случайная группа
        weightA = missingA не пуст ? 25    : 0
        weightS = missingS не пуст ? 0.54  : 0
        weightB = 100 - weightA - weightS
        group   = random_by_weight({ B: weightB, A: weightA, S: weightS })

        // 3. первая попытка и серия билетиков
        if group == B and missingA не пуст and (attempt == 1 or bStreak >= 3):
            group = A

    // 4. приз внутри группы
    if group == A:
        prize = random_equal(missingA)
    if group == S:
        prize = random_by_weight(missingS)   // стикер 0.13, хвост 0.13, VIP 0.02
    if group == B:
        prize = random_by_weight({ 25: 20, 50: 45, 75: 25, 100: 10 })

    // 5. запомнить
    if group == B:
        bStreak = bStreak + 1
        начислить prize билетиков
    else:
        bStreak = 0
        добавить prize в collected

    return prize

random_by_weight – выбор с вероятностью, пропорциональной весу. random_equal – равновероятный выбор из списка. Если попыток станет больше 18, тот же код работает: к 18-й все A уже собраны, добор не срабатывает.
