# Прототип Blink

Веб-прототип пяти экранов – карта, друзья, чаты, чат, профиль – с навигацией через таб-бар. Вёрстка сверена со скриншотами в папках проекта наложением в 390×844 @3x, поведение прокликано автотестом. Правила, по которым он собран, – в `../blink-design.md` и `../CLAUDE.md`.

## Как открыть

- Двойной клик по `index.html`. Работает без сервера, из сети грузятся только шрифты Google Fonts.
- Или сервер: `python3 -m http.server 8765 --directory prototype` из корня проекта → http://localhost:8765. В Claude Code – превью `blink-prototype` из `.claude/launch.json`.
- На телефоне (ширина ≤ 480) прототип раскрывается на весь экран с настоящими safe-area. На десктопе он в рамке телефона и сам уменьшается, если окно ниже 892 px.

Прямые ссылки на экраны: `#/map`, `#/friends`, `#/chats`, `#/checkins`, `#/profile`, `#/chat/<id>` (`masha`, `valentin`, `kapibar`, `tarakanus`, `alesya`, `kekova`, `natashka`, `vasya`, `lyova`, `sonya`).

## Навигация и поведение

| Где | Действие | Результат |
|---|---|---|
| таб-бар | любой пункт | переключение таба, скролл каждого таба сохраняется |
| чаты | строка | чат въезжает справа, счётчик непрочитанных гаснет |
| чаты | папка | фильтр списка |
| чаты | крестик баннера | баннер схлопывается |
| чаты, друзья | поиск | фильтр по имени, пустое состояние |
| друзья | „написать“ / „на карте“ | чат с другом (новый – пустой) / карта |
| друзья | „ДОБАВИТЬ“ | переключается в „добавлен“ и обратно |
| карта | пин | чат с человеком |
| чат | „назад“, Esc, свайп от левого края | возврат; свайп идёт за пальцем, решение по проекции броска |
| чат | текст + Enter или „отправить“ | сообщение в ленте; Shift+Enter – перенос строки |
| чат | „Aa“ | следующее сообщение крупным текстом, иконка меняется на крестик |
| чат | стикер в поле | панель 3D-стикеров вместо клавиатуры, стикер отправляется сообщением |
| чат | строка локации | карта |
| профиль | коллажи „друзья“, „чекины“ | соответствующий таб |
| профиль | „где учишься?“ | только отклик: экрана школ в задаче нет |

Кнопки, чьих экранов нет в задаче, только отвечают на нажатие (без тостов): „ЗАЯВКИ“, плитки „трях / номер / ссылка / тел книга“, „ЕЩЁ“, „посмотреть всех“, новый чат, звонок, фото, микрофон, тулбар и „мой мир“ на карте, кнопки профиля, „маркет“, ник, „где учишься?“.

## Фичи отдельными флоу

| Папка | Что показывает |
|---|---|
| `features/geo-share/` | шеринг геопозиции по ссылке: слева ты в приложении (свой пин → шторка „поделиться“ → геопозиция, профиль, qr-код), справа друг без blink в браузере (рамка Safari, карта с тобой, заряд и остаток времени, баннер „скачать“, конец трансляции). Сценарии и решения – в её `README.md` |
| `features/overnights/` | ночлеги: ночная карта с домами друзей, у которых ты ночевал, итог „ночлегов не дома“, коллажи „с кем чаще / ночей не дома / городов“, список-столбики и сторис – та же сводка без списка. Сценарии – в её `README.md` |

Фича подключает общие `styles/` и `assets/`. Новые общие компоненты, которые для неё понадобились, лежат в `components.css`: шторка, плитки выбора, live-точка, модификаторы пина.

## Структура

```
index.html              разметка экранов, таб-бар, рамка
styles/tokens.css       токены – единственный источник значений
styles/base.css         сброс, нативное поведение, рамка превью, статус-бар
styles/icons.css        иконки-маски (генерируется)
styles/components.css   общие компоненты
styles/screens/*.css    раскладки экранов
scripts/data.js         моковые данные
scripts/pin.js          пин на карте – одна разметка для всех экранов и фич
scripts/app.js          роутер, рендер списков, поведение
assets/                 веб-копии ассетов (генерируется)
features/<slug>/        фичи отдельными флоу на общих стилях и ассетах
tools/                  сборка и проверки
```

## Инструменты

Нужны Python 3.9+, `pip install pillow numpy scipy segno playwright` и `python3 -m playwright install chromium`.

| Команда | Что делает |
|---|---|
| `python3 prototype/tools/build_assets.py` | пересобирает `assets/` и `styles/icons.css` из папок проекта |
| `python3 prototype/tools/compare.py` | рендерит экраны и кладёт в `tools/.compare/` сравнения с референсами (рядом и наложением); `profile-full` – низ профиля против `profile_without_nav.png` |
| `python3 prototype/tools/compare.py pins` | пин во всех шести состояниях против `pin/*.png`: лист „эталон · прототип · наложение“ (`pins-side.png`) и доля отличий вне аватарки |
| `python3 prototype/tools/smoke.py` | прокликивает 70 сценариев: 29 основного прототипа, 32 „шеринга геопозиции“ и 9 „ночлегов“, ловит ошибки консоли |
| `python3 prototype/tools/measure.py` | замеры по скриншотам: полосы блоков, цвета, место ассета, подбор кегля и веса по форме букв (`fit-font`) |
| `python3 prototype/tools/check_assets.py` | проверяет, что все файлы проекта описаны в `ASSETS.md` |

## Состояние сверки

| Экран | Доля заметно отличающихся пикселей | Что отличается |
|---|---|---|
| чат | 5 % | имя и статус в шапке (см. решения), строка локации |
| профиль (с таб-баром) | 8 % | четвёртый таб, мелкие сдвиги стикер-чисел |
| профиль без таб-бара | 8 % | то же, сверено с `profile_without_nav.png` |
| чаты | 10 % | закреплены два чата вместо пяти – порядок строк другой |
| друзья | 10 % | в списке девять друзей вместо двух, карусель ушла ниже |
| карта | 24 % | другая подложка карты (ассет `map_background.png` – другой район); пины по новым правилам: наташка 52 вместо 48, лёва в сети |
| пины (`compare.py pins`) | 0.2–1.3 % вне аватарки | человек на эталонах не из пака; у офлайн „в пути“ 5 % – кадр эталона #F6F5F1 и стоит выше |

Шапки, подписи и кегли всех экранов сверены попиксельно; расхождения в чатах и друзьях – от нового наполнения, которое попросили.

## Решения и отступления от референсов

1. **Четвёртый таб – „чекины“.** На профиле и карте в таб-баре „маркет“, на друзьях и чатах – „чекины“. Выбраны чекины: маркет открывается плашкой в профиле. Вернуть маркет: в `index.html` у четвёртого пункта таб-бара поставить `data-tab="market"`, иконку `icon--market` и подпись, в `app.js` заменить `checkins` в `TABS`, добавить экран.
2. **Экрана чекинов в референсах нет** – стоит пустое состояние со звездой-маскотом.
3. **Маша.** В списке чатов она „маша“, в шапке эталонного чата – „melissa“ (одно фото). В прототипе везде „маша“, статус „в сети“ – у неё онлайн-точка в списке.
4. **Аватар в табе „ты“** на эталонах разный. В прототипе везде владелица профиля.
5. **Подложка карты** – `Map/map_background.png`, это другой район, чем на эталоне. Пины стоят на координатах эталона.
6. **Тема профиля** – картинка, восстановленная со скриншота без контента. Тему выбирает пользователь, поэтому это изображение, а не зашитый градиент.
7. **Пины** собраны по `pin/*.png`: размеры 52 / 36 / 20 – один пин в масштабе; живая аватарка в маске 62×80, r26; хвост, стрелки, домик и подложка „в сети“ – ассеты дизайнера. Живые аватарки `people/live-*.webp` собраны из пака `avatars/`: у вырезок нет запаса над головой, а в маске голова должна выходить над кадром всего на ~3 pt. Кадр офлайн „в пути“ на эталоне #F6F5F1, в прототипе белый, как в остальных офлайн-состояниях и на эталоне карты.
8. **Строка локации над композером** взята из ассета `Bottom_messenger.png`, на эталоне чата её нет. Показывается, если у собеседника есть локация.
9. **Панель стикеров и крупный текст** – трактовка кнопок „стикер“ и „Aa“ из ассетов чата; отдельных макетов нет.
10. **Статус-бар и плашка BLINK** – только в рамке превью, вырезаны со скриншота. На телефоне их нет.
11. **Шрифты.** Montserrat – Google Fonts, SF Pro – системный на Apple, на Windows и Android вместо него Inter (метрики чуть другие).
12. **Цифры на пине курсивные** (Montserrat 700 13 и подпись 700 9 #808080) – так и на эталоне карты, и во всех `pin/*.png`, проверено по наклону глифов. Прямые числа – в профиле и счётчиках. Раньше „22“ на пине по ошибке было прямым.
13. **Друзья и возможные.** В „мои друзья“ девять человек: вырезки на свечении (зелёное – в сети, серое – нет) и фото-сквирклы. В „возможных“ пять карточек, у трёх нет фото – показан сквиркл с ником.
